# MOSPL - Flutter E-commerce UI

This repository now contains a complete **frontend UI implementation** with Material 3, Riverpod state handling, reusable scaffolds/widgets, and route-based navigation.

## Included Modules
- Auth (Splash, Onboarding x3, Login, Signup)
- Home (Dashboard, Category listing, Wallets, Belts, Bags, Jackets, Accessories, Product Grid, Product Detail Carousel, Search with Filters)
- Shopping (Cart, Checkout, Address, Payment, Confirmation, Tracking + utility pages)
- User (Profile, Edit, Wishlist, Notifications, Settings, Help/Support, Privacy, About)
- Admin (Dashboard, Add/Edit Product, Sales Analytics, Order Management)
- AI Chatbot (Chat UI + History)

## UI Features
- Light premium palette (cream + leather brown)
- Dark mode toggle with Riverpod state
- Bottom navigation + drawer menu
- Animated route transitions
- Reusable scaffold pattern for scale to 150+ screens
