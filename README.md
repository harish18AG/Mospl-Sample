# MOSPL

MOSPL is a premium AI-integrated leather e-commerce mobile application for onlinemadras.com. The repository includes a Flutter Material 3 Android frontend scaffold and a production-oriented Node.js backend with Firebase and Razorpay test payment integration.

## Highlights

- Premium luxury Flutter UI with warm beige, coffee brown, matte black, cream, and soft gold palette.
- 75+ routed Flutter screens covering authentication, shopping, orders, settings, admin operations, analytics, and support.
- 120 dummy products across 10 categories with realistic Indian rupee pricing, stock, discounts, reviews, variants, and royalty-free network image URLs.
- Modular Express backend with controllers, routes, services, middleware, Firebase Admin SDK, Firestore, Storage uploads, JWT, bcryptjs, validation, Helmet, CORS, Morgan, Multer, and Razorpay.
- Razorpay test-mode payment flow: create order, verify HMAC SHA256 signature, save payment, update order, record failed payments, generate invoice data, refund API, and history API.
- Firebase schema and security rules for users, admins, products, categories, cart, wishlist, orders, payments, reviews, coupons, banners, notifications, tracking, returns, refunds, settings, analytics, activity logs, support tickets, and AI recommendations.
